## APK

```text
package: com.example.baseapp
minSdk: 24
ABI: arm64-v8a, x86_64
```

SHA-256:

```text
22FD21DF49A3C74BB445C37187EA8F8C651BD00DC98CB0942953E2027E9A53D3
```

Модели ASR/диаризации скачиваются в приложении. GGUF для локальной LLM
скачивается автоматически при первом запуске в
`files/models/llm/qwen2.5-1.5b-instruct-q4_k_m.gguf`
(инструкция — в [`../android/README.md`](../android/README.md)).

## Видео

Готовое видео: [`demo/демонстрация.mp4`](demo/демонстрация.mp4) —
2 мин 51 с, запись экрана телефона (720×1572).

Что показано:

1. Импорт `dialogs_ru_002.wav` из памяти устройства.
2. Воспроизведение с перемоткой, паузой и кнопкой «с начала».
3. Распознавание на устройстве с прогрессом сегментов.
4. Редактор реплик: два спикера, `speaker_id`, таймкоды.
5. Перекраска спикера через HSV-пикер и переименование.
6. Экспорт JSON и подтверждение сохранения файла.

Ссылку положить в [`video.md`](video.md).
